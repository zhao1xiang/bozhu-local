### 方式 1：直接运行（推荐）
1. 进入 `bozhu-client-win` 文件夹
2. 双击 `backend_server.exe` 运行
3. 程序会自动：
   - 启动后端服务
   - 打开浏览器访问 `http://127.0.0.1:38125`

```bash

```

## 🐛 故障排查

### 问题：程序无法启动
- 检查是否有其他程序占用 38125 端口
- 查看 `logs/` 目录中的日志文件

### 问题：前端页面无法加载
- 确保 `frontend` 文件夹存在且包含 `index.html`
- 检查浏览器控制台是否有错误信息

### 问题：数据库错误
- 删除 `database.db` 文件，程序会自动重建
- 检查 `database.db.backup_*` 文件是否可以恢复

## 📞 技术支持

如有问题，请查看：
1. 日志文件：`logs/server_*.log`
2. 浏览器控制台：F12 打开开发者工具
3. 后端 API 文档：访问 `http://127.0.0.1:38125/docs`
